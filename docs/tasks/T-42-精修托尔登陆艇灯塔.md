## 任务（审查方写）

**先读 `docs/ART.md`，按里面的工作顺序做**。每个模型的外形描述写进执行记录。`models3d.js` 末尾新开一段 `// ---------- T-42 ... ----------`，所有代码写在这一段里。

### 1. `tor`：9K331M“托尔-M2”自行防空系统（俄军，车头 +x）
- 外形描述：履带底盘上压着一个方正的大炮塔；炮塔前脸是一块竖立的矩形相控阵跟踪雷达，炮塔中后部顶上是垂直发射的导弹箱，最顶上是一面向后倾斜的矩形搜索雷达板。整车比 T-64 高得多，雷达板是最高点。
- 尺寸：车体长 15、宽 6.6（含履带）、车体高 3.2；炮塔长 8、宽 5.2、高 3.4；搜索雷达板 5 × 2.2，厚 0.3，下沿离地约 8.5，向后倾约 25°，用两根细支架撑在炮塔顶上。最高点约 11。
- 零件：
  - 6 对负重轮的履带（照 `m3T64` 的 `trackLoop` 写法）；
  - 驾驶员舱盖；
  - 炮塔前脸跟踪雷达板（4 × 3.2，深色，边框一圈亮部色）；
  - 炮塔中部两组发射箱盖板（每组 2 × 2 格的方形盖）；
  - 车尾排气栅；
  - 侧裙板。
- 颜色：俄军主色 `#5a5f4b`、暗部 `#3f4234`、亮部 `#686d58`；雷达面 `#2b2f2a`。
- 炮塔放进名为 `turret` 的组（残骸会去掉它）。

### 2. `serna`：“谢尔纳”级登陆艇（俄军，船首 +x，浮在水面上）
- 外形描述：方头平底的登陆艇。船首是一整块向上收起的跳板，中部是敞开的货舱，船尾是两层高的驾驶台。低矮、宽，像一只盒子。
- 尺寸：全长 17、宽 6.5；舷侧高出水面 2.2；驾驶台 3.5 × 4.5，高 3.6，在船尾 1/4 处，顶上有桅杆和一个小雷达。货舱里放两个用帆布盖着的货堆（圆角盒子）。
- 船底放在 `y = -1.8`（水面），照 `m3Raptor` 的吃水写法。
- 颜色：舰船灰 `#6b7076`，暗部 `#4d5156`，甲板 `#565a5c`；舷号用深色小块表示，不写字。

### 3. `bld:L`：蛇岛灯塔（带受损状态）
- 外形描述：一座白色八角形塔，顶上是黑色的灯室和圆顶，塔脚连着一栋平房（看守人的房子），坡屋顶。
- 尺寸：
  - 塔：底面半径 1.7，顶面半径 1.4，高 13（用 8 边的 `cyl`）；
  - 塔顶：一圈挑出的走台（半径 2.1，厚 0.3，带细栏杆），上面是灯室（半径 1.2，高 1.6，玻璃 `#223044`），再上面是深色小圆顶；
  - 平房：7 × 4.5，墙高 3.2，坡屋顶高 1.6，贴着塔的 -z 一侧；
  - 整体在 20 × 20 的格子里偏向中心。
- 颜色：墙 `#d8d2c4`，勒脚和屋顶 `#8b3a2e`（红褐色铁皮），灯室框 `#2d302a`。
- 受损（`dmg` 为真）：
  - 塔身上半截断掉，断口参差，最高点约 8；
  - 平房屋顶塌一半；
  - 墙面熏黑两处；
  - 塔脚堆一堆碎块。
  照 ART.md 检查表：塌、破、熏黑、碎块至少占三样。

### 4. 礁岩地块 `k`（`scene3d.js`）
- `TILE3` 里给 `k` 一个灰褐色 `#6f6a60`，地块顶面比普通地块略高低不平：在 `tileDetails()` 里为 `k` 加 3–5 块大小不一的扁圆礁石（`sph` 压扁，颜色 `#7a746a` / `#5f5a52`）和一两丛低矮的干草。
- `k` 格和海相邻的边，沿用 T-34 的水边泡沫条写法（水格那边已经会画，确认礁岩格旁边的海也有）。

### 5. `tb2u`：TB2 作为地图单位
- 直接复用 `m3TB2()`：`MODEL3D.tb2u = () => { const o = m3TB2(); o.scale.multiplyScalar(k); return o; }`。
- 调整 `k`，让翼展约 16。
- 螺旋桨要能转：已经在名为 `rotorX` 的组里就不用动，否则放进去。
