## 任务（审查方写）

### 背景
3D 精修模型铺开阶段。试点卡 T-16（BTR-82A）已经通过，做法照旧：**只在 `models3d.js` 末尾预留的 `// ---------- T-30 … ----------` 那一段里写代码**，写完用 `MODEL3D` 注册。

照 `m3House` 的写法。建筑函数签名是 `(seed, dmg)`，`dmg` 为 true 时画受损状态。精细度向 `m3T64` 看齐。T-16 审查时提了两点，请注意：
- 大平面上要加一层细节，不要留整片空板；
- 颜色按卡片给的值，俄军用新的深一点的色值。

### 比例
占地约 16 × 11（在一格里，四周留边），五层，每层高约 3.1，总高约 17（含屋顶）。

### 颜色
预制板墙面 `#cbc5b5`，板缝 `#9d978a`，屋顶 `#7d796f`，窗框 `#e8e4da`，亮窗 `#f6d57a`（带暖色自发光，照民房写法），暗窗 `#2d3440`。积雪 `#eef2f4`。

### 零件清单（每一项都要有，坐标可以微调）
1. 主体：一个带小倒角的长方体。
2. 板缝：每层之间一条横向的细深色条，加几条竖向的细条，把墙面分成预制板块。
3. 窗户：
   - 长边每层 5 扇，短边每层 2 扇，每扇带窗框；
   - 按 `hash(seed, …)` 让约三分之一的窗亮着，其余是暗窗。
4. 阳台：面向 +z 的长边，每层 3 个小阳台（一块挑出的楼板，加三面细栏杆或实心栏板），栏板颜色随机取 `#b9b3a4` / `#8e8a7e`。
5. 单元门：面向 +x 的短边一侧，或长边底层，2 个入口；门上有混凝土雨棚，旁边一盏小灯。
6. 屋顶：
   - 四周一圈矮女儿墙；
   - 屋顶上有 2 个楼梯间出口（小方盒）、4 根通风管；
   - 几根电视天线（细杆加横杆）；
   - 屋面积雪。
7. 受损状态（`dmg`）：
   - 一端的顶部两层塌掉：那一端的上面两层不要画，改放几块歪斜的楼板和一截露出的钢筋（细深色圆柱）；
   - 塌口附近的窗户全部变成暗窗，外墙加两块熏黑的痕迹；
   - 楼脚放一些碎块。

完好状态合格：五层、板缝、窗户（部分亮灯）、阳台、屋顶的楼梯间和天线都有。墙面发白是全局曝光的问题，审查方会统一处理。

**受损状态不合格**：现在只是把一端整齐地“切矮”了两层，看起来像一栋本来就高低错落的楼，看不出是被打塌的。要改成：
1. 塌口要参差不齐：塌掉那一端的第 4、5 层不要一刀切。
   - 保留几段高低不齐的残墙（宽 1.5~3、高度随机差 1~3 的墙片）；
   - 残墙边缘伸出几根钢筋（细深色圆柱，随机歪斜）。
2. 塌口处的楼板：2~3 块楼板（薄板，厚约 0.4）歪斜地挂在第 3 层顶上，一端搭着、一端向下垂；再加一块整个掉在楼脚。
3. 熏黑：塌口周围两层的外墙加 2~3 块焦黑的不规则斑块（`#1f1c19`、粗糙度 1），紧贴墙面；这些位置的窗户全部变成暗窗，其中两扇窗外加向上的烟熏条。
4. 楼脚碎块：沿塌口一侧的墙脚堆 8~12 块大小不一的混凝土块（照 `m3House` 受损时的写法，数量多一些）。
5. 屋顶积雪在塌口一侧不要画。
