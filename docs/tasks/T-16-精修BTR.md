## 任务（审查方写）

### 背景
游戏已经换成 3D 渲染（`game/js/scene3d.js`）。没有精修模型的单位暂时由体素模型自动转成 3D 兜底，所以看起来还是方块。

`game/js/models3d.js` 里的 `m3T64()` 是审查方写的范本，精细度要向它看齐：
- 负重轮分三层（橡胶胎、轮毂、轴盖）；
- 履带逐块排列；
- 装甲块带倒角；
- 细节有层次（舱盖、观察窗、发烟器、天线）。

这是精修模型的**试点卡**，审查方会按 T-64 的标准严格对比。先读一遍 `m3T64()`，照它的写法来。

### 要做的事
在 `models3d.js` 里写 `m3Btr(cmd)`，并注册：`btr: () => m3Btr(false), cmd: () => m3Btr(true)`。

**比例**：一格 = 20，约 2 个单位 = 1 米，高度略微夸张（约 1.3 倍），和 T-64 保持同一套比例。
- BTR-82A 实车长 7.65 米、宽 2.9 米。
- 模型车体长约 15.5（x 约 -7.7 到 7.9），含车轮总宽约 7。
- 炮塔顶高约 6，和 T-64 并排时明显比坦克矮、比坦克窄。

**颜色**（俄军涂装）：
- 车体：主色 `#6b705a`，暗部 `#4a4d3c`，亮部 `#7a7f68`；
- 轮胎橡胶 `#1e201d`；
- 金属件：钢件 `#5d625c`，深色件 `#2d302a`；
- 观察窗玻璃 `#223044`；
- 不画任何字母标记（不要 Z、V）。

**零件清单**（坐标是建议值，可以微调，但每一项都要有）：

1. **车轮 8 对**：四根轴，x 约 -5.4、-2.8、1.2、3.8；第 2、3 轴之间留出车门的空当。
   - 每个车轮三层：
     - 橡胶胎 `cyl(1.35, 1.35, 1.0, 24)`；
     - 轮毂：直径约 0.6 倍，比胎宽略厚；
     - 轴盖：钢色，最外层。
   - 车轮中心约 y = 1.35，z = ±3.3。
2. **车体**：用 `profile()` 做船形侧面再挤出，宽约 5.4。
   - 前端是向上翘的船首：底边前端上斜，前上方是斜的首上装甲；
   - 后端略收。
3. **上部斜侧板**：两侧各一块沿车身的长板，向内倾斜（BTR 的上车体两侧是向内斜的）。
4. **车顶板**：平板，略带倒角。
5. **轮拱挡泥板**：车轮上方沿车身的深色护板。
6. **侧门**：第 2、3 轴之间的舱门，两侧各一，比车体略暗，带一根把手。
7. **观察窗**：上部斜侧板上每侧 5 个小观察窗（深色玻璃块）。
8. **首部**：
   - 折叠的防浪板：一块斜贴在首上装甲上的薄板；
   - 两个车灯（参照 T-64 车灯的写法，带微弱自发光）；
   - 两个拖钩。
9. **驾驶员舱盖、车长舱盖**：车顶前部两个圆盖，稍微凸起。
10. **炮塔**（BPPU，放进名为 `turret` 的组，位置约 x = 0.8、车顶上方）：
    - 座圈：扁圆柱；
    - 炮塔主体：带斜面的 `profile()` 块，宽约 3；
    - 30 毫米机关炮：
      - 细长炮管，从炮塔前伸到 x 约 9；
      - 炮口制退器：短粗段；
      - 身管根部有一段较粗的套管；
    - 并列机枪：炮管旁一根更细的枪管；
    - 瞄准镜：炮塔顶部一个带玻璃的小盒；
    - 发烟器：炮塔两侧后部，每侧 3 个；
    - 天线：炮塔后部一根细杆。
11. **车尾**：
    - 发动机格栅：车顶后部 6~8 根横向细条；
    - 排气口：右后侧一个深色排气盒，带一点烟熏的暗色；
    - 车尾杂物箱：一个。
12. **指挥车变体**（`cmd = true`）：
    - 不要机关炮和炮塔，改成一个稍高的指挥塔，放进 `turret` 组；
    - 车顶加一个电台箱；
    - 车顶加三根天线：
      - 细杆，高约 7；
      - 底座是短粗的绝缘座；
      - 位置沿车身前、中、后分开，不要挤在一起；
    - 其余和 BTR 相同。

**枪口位置**：`MUZZLE.btr` 是 `[9, 0, 7]`（体素坐标，高度 7 个体素约等于 3D 里的 5.7）。炮口尽量落在 x ≈ 9、高度 ≈ 5.7 附近。若差得多，在执行记录里写出实际值，审查方来改。
