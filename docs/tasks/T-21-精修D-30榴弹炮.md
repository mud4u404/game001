### 零件清单（每一项都要有，坐标可以微调）
1. 三条大架呈 120° 张开平放在地上（每条是细长的倒角盒子，末端有驻锄），其中一条朝 -x 方向。
2. 中央千斤顶底座：一个圆盘加一个短圆柱。
3. 两个车轮抬离地面，挂在炮架两侧（射击状态的 D-30 车轮是离地的）。
4. 摇架与炮管：
   - 炮管从 x 约 2 伸到 13，逐渐变细；
   - 炮口是多孔制退器（一段粗圆柱，两侧各开 3 个小槽，槽用深色小盒表示）；
   - 炮管上方是两根驻退复进机圆筒。
5. 小防盾：炮管两侧的斜板，带一个瞄准镜开口。
6. 瞄准镜与高低机、方向机的手轮：手轮是小圆环，放在炮尾左侧。
7. 炮组：一名跪姿士兵手持炮弹（黄铜弹壳加灰色弹头）在炮尾；一名站姿士兵在瞄准镜旁。`gun: none`。
8. 两个弹药箱，其中一个打开，露出两发炮弹。
9. 炮口位置：`MUZZLE.d30` 是 `[13, 0, 4]`，炮口应在 x 约 13、高约 3.3 附近。
