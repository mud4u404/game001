## 任务（审查方写）

### 背景
现在电网 7 格贯穿整个战役，每关结束只回 1 格。电网归零时直接删除存档、从第一关重来（`ui.js` 的 `showDebrief` 里 `store.del('sunflower-v1')`）。
玩家在第一章打砸一关，后面基本救不回来，最后只能整局重开。这是目前最大的“无论如何都过不去”的问题。

### 要做的事
1. **章节开始时电网回满，并记一个存档点**
   - 在 `ui.js` 里新增函数 `chapterCheckpoint()`：
     - 执行 `CAMP.grid = CAMP.gridMax`；
     - 执行 `CAMP.chk = JSON.parse(JSON.stringify(Object.assign({}, CAMP, { chk: null })))`，存的是不含自身的深拷贝；
     - 最后 `store.set('sunflower-v1', CAMP)`。
   - 调用它的两个地方：
     - `btnNew` 的点击处理里，`CAMP = freshCamp()` 之后调用；
     - `continueCampaign()` 里 `if (b !== a)` 的分支，在播放新章节序幕之前调用。
2. **电网崩溃不再删档，改成回到本章开头**
   - `showDebrief` 里电网归零的分支：删掉 `store.del('sunflower-v1')`，其余不变，照常显示 `#gameover`。
   - `index.html` 的 `#gameover`：
     - 文案改为“城市陷入黑暗，防线随之瓦解。可以从本章开头重新推演。”；
     - 按钮 `#btnRestart` 的文字改为“从本章开头重来”；
     - 在它后面加一个普通按钮 `<button class="btn" id="btnGiveUp" type="button">重新开始战役</button>`。
   - `ui.js`：
     - `#btnRestart`：若 `CAMP.chk` 存在，执行 `CAMP = Object.assign(freshCamp(), JSON.parse(JSON.stringify(CAMP.chk)))`，再补回存档点 `CAMP.chk = 上面那份拷贝`，然后 `store.set` 并 `showCampaign()`；
     - 若 `CAMP.chk` 不存在（旧存档），效果等同于 `#btnGiveUp`；
     - `#btnGiveUp`：`CAMP = freshCamp()`，调用 `chapterCheckpoint()`，播放第一章序幕，再进入战役地图（和 `btnNew` 一样）。
   - `btnRestart` 现在绑定在 `ui.js` 末尾（`CAMP = freshCamp(); showTitle();`）。直接替换这一行的逻辑，不要重复绑定。
3. **难度选项（标题画面）**
   - `freshCamp()` 增加字段 `easy: false`。
   - `index.html` 的标题画面，在 `.row` 里 `#btnSpeed` 后面加一个 `<button class="btn small" id="btnDiff" type="button">`，风格与同行按钮一致。
     - 文字为“难度：普通”或“难度：简单”，点击后切换；
     - 当前选择存到 `store.set('sunflower-diff', true/false)`，标题画面打开时读取。
   - `btnNew` 创建新战役时，把 `CAMP.easy` 设为当前选择。
   - `battle.js` 的 `endMission` 里，任务结束修复电网的那一行，修复量改为 `CAMP.easy ? 2 : 1`，且不超过 `gridMax`。
     - `res.repair` 记录实际修复量；
     - `ui.js` 结算里的文字 `'后方抢修队连夜作业：电网 +1。'` 改为使用 `res.repair` 的实际数值。
   - 简单模式只改变修复量，其他数值一律不变。

### 验收标准
1. `node tools/check.js` 通过。
2. `node tools/playtest.js /tmp/pt-T-11` 输出 `ERRORS none`，退出码 0。
3. 在执行记录里写一段手动验证（可以用 playwright 或 `window.__sf` 完成），依次确认：
   - (a) 新战役开始后 `CAMP.chk` 存在；
   - (b) 把 `CAMP.grid` 设为 1，并让一栋电网建筑被击中后，出现 `#gameover`，且 localStorage 里 `sunflower-v1` 仍然存在；
   - (c) 点击“从本章开头重来”后回到战役地图，`CAMP.mission` 是本章第一关，电网是满的。
4. 截图 `docs/tasks/shots/T-11/gameover.png`：电网崩溃画面，两个按钮都可见。

### 不要做
- 不要改任务数据、敌军数值和电网上限。
- 不要改 `tools/playtest.js`。
