## 任务（审查方写）

### 背景
3D 精修模型铺开阶段。试点卡 T-16（BTR-82A）已经通过，做法照旧：**只在 `models3d.js` 末尾预留的 `// ---------- T-20 … ----------` 那一段里写代码**，写完用 `MODEL3D` 注册。

用 `soldier3()` 搭人物（`gun: none`、`band: null`），`vest` 当作外套颜色，`uni` 当作裤子颜色。精细度向 `m3T64` 看齐。T-16 审查时提了两点，请注意：
- 大平面上要加一层细节，不要留整片空板；
- 颜色按卡片给的值，俄军用新的深一点的色值。

### 比例
四个人占一格，面向 +x（行进方向）。孩子用 `soldier3` 建好后整体缩放 0.65。

### 颜色
冬季外套用低饱和的颜色：`#7a4b3a`、`#3d4f6b`、`#6b6a5e`、`#8a7a52`；裤子 `#2f3035` / `#3b3a36`。皮肤 `#e0b896` 或 `#d6ad86`。

### 零件清单（每一项都要有，坐标可以微调）
1. 老年妇女：戴头巾（`hat` 用 `#8a3a3a`，再在帽子下方加一段围住脖子的扁圆环），手里提一个布包。
2. 男人：手提一个行李箱（深棕色带倒角的盒子，加一个把手），另一只手搭在孩子肩上的位置。
3. 女人：背一个双肩包，牵着孩子。
4. 孩子：缩放 0.65，戴红色毛线帽，怀里抱一个小玩具（小熊：两个小球加两个耳朵）。
5. 人物不要拿武器，不要戴头盔，不要有臂章。

### 验收标准
1. `node tools/check.js` 通过；`node tools/playtest.js /tmp/pt-T-20` 输出 `ERRORS none`；`node tools/shot3d.js /tmp/s3-T-20` 输出 `SHOT3D OK`。

3. 执行记录里逐条写出零件清单各项在截图里的位置（照 T-16 的写法），有炮口要求的写出实际坐标。
