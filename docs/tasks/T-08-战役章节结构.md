### 要做的事
1. **章节数据**（`data.js`，放在 `MISSIONS` 之后）

   - 新增：

   - 加一个工具函数：`const chapterOf = mi => MISSIONS[mi] ? MISSIONS[mi].chapter : CHAPTERS.length - 1;`
2. **地图数据改成按章节配置**（`ui.js`）
   - 把 `const GEO = {...}` 改为 `const GEOS = { kyiv: {...}, odesa: {...} }`。

   - `renderCampaign`：用 `const G = GEOS[CHAPTERS[chapterOf(CAMP.mission)].geo];` 取当前地图，然后：
     - 所有 `GEO.xxx` 改为 `G.xxx`。
     - 用 `for (const w of G.water) poly(w, '#2f5f80')` 和 `for (const [pts, w] of G.rivers) path(pts, '#2f5f80', w)` 替代原来逐个画水库和河流的代码。

3. **标题按章节显示**
   - `index.html`：把 `<div class="ctop"><h2>战区一 · 基辅之冬</h2><span>基辅州战略态势 · 2022年2–3月</span></div>` 改为 `<div class="ctop"><h2 id="cTitle"></h2><span id="cSub"></span></div>`。
   - `ui.js` 的 `showCampaign`：填入 `CHAPTERS[当前章节].name` 和 `.sub`。右侧的“战役进程”列表只列出当前章节的任务。
4. **章节切换**（`ui.js` 的 `continueCampaign`）
   - 原逻辑：`CAMP.mission` 超过最后一个任务时播放 `EPILOGUE` 然后回标题。改为：
     - 刚完成的任务所在章节为 `a`，下一个任务 `CAMP.mission` 所在章节为 `b = chapterOf(CAMP.mission)`。
     - 如果 `CAMP.mission >= MISSIONS.length`：播放 `CHAPTERS[a].epilogue` 后回标题（和现在一样）。
     - 否则如果 `b !== a`：先播放 `CHAPTERS[a].epilogue`，再播放 `CHAPTERS[b].prologue`，然后 `showCampaign()`。
     - 否则：直接 `showCampaign()`（和现在一样）。
   - `playStory` 遇到空数组时直接调用回调。
   - 开始新战役时仍然播放 `CHAPTERS[0].prologue`。
5. **验证脚本 `tools/campaign-shot.js`**：`node tools/campaign-shot.js <输出目录>`
   - 写法参照 `tools/gallery-shot.js`，有任何 `pageerror` 就以退出码 1 结束。
   - 截图 1：`SPEED = 0.01; CAMP = freshCamp(); showCampaign();`，等 1 秒，保存为 `kyiv.png`。
   - 截图 2：在页面里临时 `MISSIONS.push(Object.assign({}, MISSIONS[0], { id: 'test2', code: '2-1', name: '测试任务', chapter: 1, mapPos: [0.56, 0.54] }))`，然后 `CAMP.mission = MISSIONS.length - 1; showCampaign();`，等 1 秒，保存为 `odesa.png`。
   - 断言：截图 2 时 `#cTitle` 的文字是“战区二 · 黑海”，并且 `#cList` 里只有 1 行任务。通过时打印 `CAMPAIGN OK`。
