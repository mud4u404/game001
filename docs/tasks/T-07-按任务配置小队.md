# T-07 按任务配置小队与新角色

- 改动范围：`game/js/ui.js`、`game/js/data.js`、`tools/terrain-shot.js`
- 依赖：T-06

## 任务（审查方写）

### 背景
战斗界面左上角的我方单位名单，目前在 `ui.js` 里写死成了 `['t64', 'atgm', 'd30']`。第二章会换成海上小队，所以名单要改成由每个任务的 `squad` 决定。T-06 新增的两个我方单位还需要对应的角色（名字、代号、像素头像）。

### 要做的事
1. **名单由任务决定**（`ui.js` 的 `renderHud`）
   - 把 `['t64', 'atgm', 'd30'].map(...)` 改为 `Object.keys(B.mission.squad).map(...)`。
   - 在 `ui.js` 里搜索 `'t64'`、`'atgm'`、`'d30'`，确认没有其他地方写死了小队组成。如果有，同样改成从 `B.mission.squad` 读取，并在执行记录里列出来。
2. **两名新角色**（`data.js` 的 `CHARS`，加在 `ivanna` 后面）
   ```js
   olena:  { name: '奥列娜·克拉夫丘克 中士', call: '海燕', role: '无人艇操作员', face: { skin: '#e8c0a0', hair: '#2a2420', style: 'beanie', headset: true, uniform: '#2f3b4a' } },
   dmytro: { name: '德米特罗·邦达连科 上尉', call: '灯塔', role: '“海王星”发射车车长', face: { skin: '#d8ae88', hair: '#4a3a2a', style: 'helmet', mustache: '#3a2a20', uniform: '#4d5733' } },
   ```
   人物为虚构，姓名只用常见的乌克兰姓名。头像由 `ui.js` 的 `portrait()` 按 `face` 参数自动生成，不需要改 `portrait()`。
3. **`tools/terrain-shot.js` 加一张小队截图**，写在 T-06 的海战断言之后：
   1. 在页面里执行：`MISSIONS[1].squad = { magura: [2, 6], neptune: [3, 3], atgm: [4, 3] }; newBattle(1);`，然后照原来的方式把第 4 行改成沙滩、第 5–7 行改成外海。
   2. `SCENE = 'battle'; B.phase = 'player'; show('hud'); selectUnit(B.units.find(u => u.type === 'magura')); renderHud();`
   3. 等 1 秒，截图保存为 `<输出目录>/squad.png`。
   4. 断言：`document.querySelectorAll('#roster .rchip').length === 3`，并且名单文字里包含“无人艇”“海王星”“标枪/毒刺”。全部通过时打印 `SQUAD OK`。
   5. 截完图后恢复 `MISSIONS[1].squad` 的原值，避免影响同一页面里的后续操作。

### 验收标准
1. `node tools/check.js` 通过。
2. `node tools/playtest.js /tmp/pt-T-07` 输出 `ERRORS none`（第一章的名单必须和原来完全一样）。
3. `node tools/terrain-shot.js docs/tasks/shots/T-07` 打印 `TERRAIN OK`、`NAVAL OK`、`SQUAD OK`，退出码 0。
4. `docs/tasks/shots/T-07/squad.png` 里，左上角名单是无人艇、海王星、标枪/毒刺三项，头像各不相同；左下角的单位卡显示“海燕”的头像和名字。

### 不要做
- 不要改第一章三个任务的 `squad`。
- 不要改 `portrait()` 的绘制代码。
