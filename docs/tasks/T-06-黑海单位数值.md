## 任务（审查方写）

### 背景
T-03 做好了三个模型，T-04 做好了海域地形和舰艇移动。这张卡给三个单位配上属性和武器，让它们能在规则层面参战。关卡和小队配置不在这张卡里（T-07 和后续任务卡负责）。

史实依据：
- “海王星”R-360 反舰导弹 2022 年 4 月击沉了“莫斯科”号巡洋舰，是岸基发射。
- 乌克兰从 2022 年 10 月开始使用海上无人艇袭击塞瓦斯托波尔。“海马 V5”这个型号 2023 年才公开，所以游戏里的单位统称“海上无人艇”，只在第二章后期任务出场。
- 03160 型“猛禽”巡逻艇 2022 年在蛇岛附近被 TB2 击毁过多艘，艇上主要武器是一挺 12.7 毫米机枪。

### 要做的事
1. **`data.js` 的 `UNITS`**，在 `civ` 前面新增三个单位：
   ```js
   magura:  { name: '海上无人艇', short: '无人艇', team: 'ua', cls: 'la', hp: 1, move: 5, mob: 'sea', weapons: ['seaRam'], pilot: 'olena', desc: '装满炸药的无人快艇。撞击目标后引爆，自身随之损失。' },
   neptune: { name: '“海王星”发射车', short: '海王星', team: 'ua', cls: 'soft', hp: 2, move: 3, mob: 'wheel', weapons: ['neptune'], pilot: 'dmytro', desc: '岸基反舰导弹发射车，只能攻击水面舰艇。' },
   raptor:  { name: '03160 型“猛禽”巡逻艇', team: 'ru', cls: 'la', hp: 2, move: 5, mob: 'sea', atk: 'kord', armor: true },
   ```
   `pilot` 引用的两个角色由 T-07 添加，这张卡先不用管。
2. **`data.js` 的 `WEAPONS`**，在 `tb2` 后面新增：
   ```js
   seaRam:  { name: '撞击引爆', kind: 'melee', dmg: { la: 4, ha: 4, soft: 4, inf: 2, bld: 1 }, selfDestruct: true, fx: 'rpg', desc: '撞击相邻目标并引爆，4 点伤害。无人艇随之损失。' },
   neptune: { name: 'R-360 反舰导弹', kind: 'naval', min: 2, range: 8, ammo: 'nep', dmg: { la: 4, ha: 4, soft: 3 }, fx: 'atgm', desc: '锁定 2–8 格内的水面舰艇，4 点伤害。每场任务 2 发。' },
   ```
   在 `vikhr` 后面新增：
   ```js
   kord:    { name: '12.7毫米机枪', kind: 'line', range: 3, dmg: { inf: 2, soft: 2, la: 1, ha: 0, bld: 1 }, fx: 'mg' },
   ```
3. **`battle.js` 的规则**
   - `mkUnit`：在 `atgm` 那行下面加 `if (type === 'neptune') u.ammo.nep = 2;`。
   - `weaponTargets`：目前我方武器没有 `melee` 和 `naval` 两种类型。在 `kind === 'any'` 那一行前面新增两个分支：
     - `melee`：上下左右 4 个相邻格，只要在地图内就加入。
     - `naval`：遍历所有存活单位，`U(o).mob === 'sea'` 且曼哈顿距离在 `[w.min, w.range]` 之间的，加入它所在的格子。
   - `playerFire`：在 `await applyEffects(eff, u);` 之后加一行：`if (w.selfDestruct && !u.dead) await killUnit(u, null, 'expend');`。
   - `killUnit`：
     - 我方单位被摧毁时的提示 `toast(\`${d.name} 被摧毁\`, 'bad')`，在 `how === 'expend'` 时改为 `toast(\`${d.name} 完成攻击\`, '')`。
     - 动画分支 `if (how === 'drown')` 改为 `if (how === 'drown' || how === 'expend')`，让无人艇沉入水中，而不是留下残骸。
4. **`tools/terrain-shot.js` 加上海战断言**。在现有 4 个断言之后、截图之前，继续在同一个页面里做（需要 `await`，把 `page.evaluate` 改成 async 函数）：
   1. `const nep = mkUnit('neptune', 3, 3)`，`const rap = mkUnit('raptor', 3, 7)`，`const tank = mkUnit('t72', 5, 3)`，全部 `push` 进 `B.units`。
   2. 断言：`weaponTargets(nep, 'neptune')` 包含 `(3,7)`，不包含 `(5,3)`。
   3. 断言：`nep.ammo.nep === 2`。
   4. `const mg = mkUnit('magura', 3, 6)`，`push` 进 `B.units`。执行 `await playerFire(mg, 'seaRam', weaponTargets(mg, 'seaRam').find(p => p.x === 3 && p.y === 7))`。
   5. 断言：`rap.dead === true`，`mg.dead === true`，`B.stats.kills === 1`。
   6. 全部通过时，在 `TERRAIN OK` 下一行再打印 `NAVAL OK`。
