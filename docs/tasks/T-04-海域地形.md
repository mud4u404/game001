# T-04 海域地形与舰艇移动

- 改动范围：`game/js/data.js`、`game/js/battle.js`、`game/js/render.js`、`tools/terrain-shot.js`
- 依赖：无

## 任务（审查方写）

### 背景
第二章“黑海”的战场在海岸线上，需要两种新地形和一种新的移动方式。这张卡只做规则和画面，不做新单位（T-03 负责模型，后续卡负责数值），也不做关卡。
现有代码里判断“是不是水”的地方都写死了 `t.t === 'w'`（伊尔平河），要统一改成一个函数，让外海也算水。

### 要做的事
1. **两种新地形**（`data.js` 的 `TILE`）
   - `o`：`{ name: '外海', note: '只有舰艇和两栖车辆能进入。地面单位落水即沉没' }`
   - `s`：`{ name: '沙滩', note: '车辆移动消耗 2' }`
2. **统一的水域判断**（`battle.js`）
   - 在 `bldAlive` 附近新增 `const isWater = t => t.t === 'w' || t.t === 'o';`
   - 把 `battle.js` 和 `render.js` 里所有用来判断“这格是不是水”的 `t.t === 'w'`、`!== 'w'`、`TILEAT(x, y).t === 'w'`，改为 `isWater(...)`。目前共 8 处：battle.js 第 53、55、239、310、479 行附近，render.js 第 173、193 行附近，以及 render.js 第 253–254 行“岸边阴影”的判断（改成邻格“不是水也不是断桥 `d`”）。
   - 不要改 `drawTile` 里决定用哪套颜色的 `key` 计算，那一段按下面第 4 条单独处理。
3. **舰艇移动**（`battle.js` 的 `moveCost`）
   - 新增移动类型 `mob: 'sea'`：在 `isWater(t)` 的格子上消耗 1，其他格子一律 `Infinity`。这个判断放在 `if (d.mob === 'air') return 1;` 的下一行。
   - 沙滩 `s`：步兵消耗 1，车辆消耗 2（和农田一样），不需要额外写代码，确认现有的“其他情况返回 2”能覆盖即可。
   - 两栖车辆进入外海 `o` 消耗 2，和河流一样。
4. **推击规则**（`battle.js` 的 `pushUnit`）
   - 舰艇（`mob === 'sea'`）被推向非水域的格子时，视为撞上障碍：自己受 1 点伤害，不移动（参照现有“撞上森林”的写法）。
   - 舰艇被推进水里不会沉没。现有判断是 `!air && !U(v).amph`，加上 `U(v).mob !== 'sea'`。
5. **画面**（`render.js` 的 `drawTile`）
   - `TCOL` 新增 `o: ['#24587d', '#15334a', '#1b4260']`、`s: ['#c9b88a', '#4a3d2d', '#5c4b37']`。
   - 外海 `o` 和河流 `w` 共用水面的绘制分支（岸边阴影、闪烁的水光），但颜色取 `TCOL.o`。另外每格多画 3 道白色浪花：每道是一段 6×1 的像素，颜色 `#dfeaf0`，位置用 `hash(x, y, i)` 在格内随机，只在 `Math.sin(t * 1.2 + i) > 0.5` 时显示。
   - 沙滩 `s` 走普通地面的纹理分支，噪点颜色用 `#dcc99a`（40%）、`#b3a172`（40%）、`#8f7f5a`（20%）。
6. **验证脚本 `tools/terrain-shot.js`**：`node tools/terrain-shot.js <输出目录>`
   - 写法参照 `tools/gallery-shot.js`：用 playwright 打开 `game/index.html`，有任何 `pageerror` 就以退出码 1 结束。
   - 在页面里执行：`SPEED = 0.01; CAMP = freshCamp(); newBattle(1);`，然后把 `B.tiles` 的第 5、6、7 行（y = 5..7）全部改成外海 `{ t: 'o' }`，第 4 行改成沙滩 `{ t: 's' }`，再令 `SCENE = 'battle'; B.phase = 'player'; show('hud');`，等 1 秒后截图保存为 `<输出目录>/terrain.png`。
   - 同时在页面里做 4 个断言，任何一个不成立就打印原因并以退出码 1 结束：
     1. `moveCost` 对 T-72（`mkUnit('t72', 0, 0)`）在外海格返回 `Infinity`。
     2. 对 BTR（`mkUnit('btr', 0, 0)`）在外海格返回 2。
     3. 临时定义 `UNITS.testboat = { name: '测试艇', team: 'ru', cls: 'la', hp: 2, move: 4, mob: 'sea' }`，`mkUnit('testboat', 0, 7)` 对外海返回 1，对沙滩返回 `Infinity`。
     4. 对步兵（`mkUnit('vdv', 0, 0)`）在沙滩格返回 1。
   - 全部通过时打印 `TERRAIN OK`。
