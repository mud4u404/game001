## 任务（审查方写）

### 背景
3D 精修模型铺开阶段。试点卡 T-16（BTR-82A）已经通过，做法照旧：**只在 `models3d.js` 末尾预留的 `// ---------- T-17 … ----------` 那一段里写代码**，写完用 `MODEL3D` 注册。

每个模型都用 `soldier3()` 搭人物，用 `m3T64` 的写法搭武器。精细度向 `m3T64` 看齐。T-16 审查时提了两点，请注意：
- 大平面上要加一层细节，不要留整片空板；
- 颜色按卡片给的值，俄军用新的深一点的色值。

### 比例
两名士兵站在同一格，总占地不超过格子的 60%。人物高度按 `soldier3` 默认（约 4.4）。

### 颜色
乌军人物：`uni #5d6b3e`、`vest #4a5533`、`helmet #4c5732`，黄色臂章（`soldier3` 默认）。发射筒 `#5d6448`，CLU 瞄准具 `#3b3f33`。

### 零件清单（每一项都要有，坐标可以微调）
1. 士兵 A（跪姿，约 x 1.5、z -2，面向 +x）肩扛 FGM-148 标枪：发射筒 `cyl(0.36, 0.36, 5.5)`，两端各一个稍粗的端盖；筒前段下方挂 CLU 指挥发射单元（带倒角的盒子），左侧有一个伸出的目镜。
2. 士兵 B（站姿，约 x -1.5、z 2.5）肩扛 FIM-92 毒刺：更细更长的发射筒（约 7），前端下方有握把，筒前部上方有一片折叠的敌我识别天线（细框加三根横杆）。
3. 士兵 A 是“教授”：在头盔下方加一副细框眼镜（两个小圆环，深色）。
4. 地上一个打开的弹药箱（`rbox` 箱体加半开的盖子），里面露出一截备用发射筒。
5. 两人脚边各放一个背包或弹药袋。
6. 炮口位置：`MUZZLE.atgm` 是 `[4, -1, 6]`，标枪筒前端应在 x 约 4、高约 4.9 附近。

### 验收标准
1. `node tools/check.js` 通过；`node tools/playtest.js /tmp/pt-T-17` 输出 `ERRORS none`；`node tools/shot3d.js /tmp/s3-T-17` 输出 `SHOT3D OK`。

3. 执行记录里逐条写出零件清单各项在截图里的位置（照 T-16 的写法），有炮口要求的写出实际坐标。
