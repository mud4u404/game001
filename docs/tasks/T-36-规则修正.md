## 任务（审查方写）

### 背景
审查战区一时发现三处规则错误，都在 `battle.js`。只修这三处，不要顺手改别的。

### 要做的事

**1. 提前结束会吞掉还没完成的目标（严重）**

`enemyPhase()` 里有这一句：
```js
if (B.turn >= B.maxTurn || (!ru().length && !B.waves.some(w => w.turn > B.turn))) { ...endMission('done'); }
```
敌人一清空就结束任务。结果：
- 1-1：第 3 回合把敌人打光，跑道只有 2 个坑，任务直接判“未完成”——玩家打得越好越吃亏；
- 1-2：第 3 批平民还在路上，任务就结束了，“3 批全部过河”拿不到。

改成：只有同时满足下面三条才提前结束，否则照常打到最后一回合：
- 场上没有俄军单位，也没有后续增援（保留原条件）；
- 所有 `kind === 'primary'` 的目标都已完成。判定方法和 `endMission()` 里一致：`r.inverse ? r.cur <= r.max : r.cur >= r.max`。请抽成一个函数 `primaryDone()`，`endMission()` 里的判断也改用它；
- 如果任务有平民（`B.mission.civ`）：所有批次都已出发（`B.civNext >= civ.groups.length`），并且场上没有平民单位。

敌人已清空、但任务还没提前结束时，只提示一次（用 `B.said.cleared` 防重复）：
`hint('敌军已肃清。完成主要目标后任务结束，最晚到第 N 回合。')`，N 是 `B.maxTurn`。

**2. 增援会刷在残骸或水里**

`enemyPhase()` 第 5 步放增援时，只检查了格子上有没有单位。增援标记落在残骸（1-3 公路上常见）、活着的建筑或地面单位不能进入的格子时，会刷在残骸上面，并卡在那里。

改法：
- 新增函数 `canStand(type, x, y)`：格子在棋盘内、没有单位，并且对这种单位移动消耗不是 `Infinity`。可以先 `mkUnit` 出一个临时单位，交给 `moveCost()` 判断；也可以把判断写成只看 `type` 的版本，但结果必须和 `moveCost()` 一致。空中单位只需要格子在棋盘内、没有单位。
- `freeNear(x, y)` 改成 `freeNear(x, y, type)`，只返回 `canStand` 为真的格子。
- 放增援时：
  - 标记格被我方单位占着：保持原来的“堵住、受 1 点伤害”规则；
  - 其余情况只要 `!canStand(m.type, m.x, m.y)`，就用 `freeNear` 找旁边的格子；
  - 找不到就不刷，并 `toast('敌军增援受阻', 'good')`。

**3. 推击、撞击、落水击杀不记功**

`pushUnit()` 造成的伤害（撞到单位、撞到建筑、落水沉没）调用 `damageUnit` 和 `killUnit` 时没有传 `src`，所以：
- 开炮的单位拿不到经验；
- 敌人被撞死、淹死时不算击杀者。

改法：
- `pushUnit(v, dir, src)` 增加 `src` 参数；
- 里面所有 `damageUnit(...)` 和 `killUnit(v, null, 'drown')` 都传 `src`；
- `applyEffects()` 调用 `pushUnit` 时把 `src` 传进去。

注意：被撞的一方如果是我方单位，照样扣血，不给任何人经验（`killUnit` 里只有击杀俄军才加经验，本来就是这样）。
