# T-33 精修 3D 模型：建筑废墟 bld:rubble 与伊尔平断桥 prop:bridge

- 改动范围：`game/js/models3d.js`
- 依赖：—

## 任务（审查方写）

### 背景
3D 精修模型铺开阶段。试点卡 T-16（BTR-82A）已经通过，做法照旧：**只在 `models3d.js` 末尾预留的 `// ---------- T-33 … ----------` 那一段里写代码**，写完用 `MODEL3D` 注册。

照 `m3House` 的写法。废墟签名 `(seed)`，断桥不带参数。精细度向 `m3T64` 看齐。T-16 审查时提了两点，请注意：
- 大平面上要加一层细节，不要留整片空板；
- 颜色按卡片给的值，俄军用新的深一点的色值。

### 比例
都在一格内。废墟最高约 5；断桥横跨河道（沿 +x 方向），桥面原高约 3。断桥所在格是水面（水面高度 y = -1.8）。

### 颜色
混凝土 `#9a958a` / `#7f7a70`，砖 `#8f5a45`，钢筋 `#3a3530`，焦黑 `#1f1c19`，木板 `#8a6a48`，积雪 `#eef2f4`。

### 零件清单（每一项都要有，坐标可以微调）
1. 废墟 `m3Rubble(seed)`：
   - 一大堆碎块：10~16 块大小不一、随机倾斜的混凝土板和砖块（`rbox` 加 `hash` 随机旋转和位置）；
   - 一截残墙：带一个窗洞的墙片，边缘参差（用几块高低不齐的盒子拼）；
   - 几根弯曲、露出的钢筋；
   - 零星积雪和一小片焦黑的地面；
   - 不同 `seed` 看起来要不一样。
2. 断桥 `m3BridgeRuin()`（伊尔平河上被炸断的公路桥，平民踩着桥下的木板撤离）：
   - 两个混凝土桥墩从水里伸出（y 从 -3 到 2）；
   - 两段断裂的桥面板：一端还搭在桥墩上，另一端斜插进水里；
   - 断口露出钢筋，桥面边缘有残留的护栏；
   - 桥下有一条木板便桥：沿 +x 方向，一排木板铺在几个木桩或水泥块上，高度贴近水面（y 约 -1.4），一侧有简易扶手（细木杆）；
   - 这是游戏里平民撤离的路线，便桥必须清楚可见，不能被桥面板挡住。
3. 分别注册 `MODEL3D['bld:rubble']` 和 `MODEL3D['prop:bridge']`。

1. `node tools/check.js` 通过；`node tools/playtest.js /tmp/pt-T-33` 输出 `ERRORS none`；`node tools/shot3d.js /tmp/s3-T-33` 输出 `SHOT3D OK`。
2. 截图放进 `docs/tasks/shots/T-33/`：
   - `node tools/model-shot.js docs/tasks/shots/T-33 bld:rubble` 生成 `bld_rubble.png`
   - `node tools/model-shot.js docs/tasks/shots/T-33 prop:bridge` 生成 `prop_bridge.png`
   - `m1-turn1.png`：从 shot3d 的输出目录复制（1-2 伊尔平，场上能看到这个模型）
3. 执行记录里逐条写出零件清单各项在截图里的位置（照 T-16 的写法），有炮口要求的写出实际坐标。
