# T-15 单位经验与晋升

- 改动范围：`game/js/data.js`、`game/js/battle.js`、`game/js/ui.js`、`game/index.html`
- 依赖：T-14

## 任务（审查方写）

### 背景
名册里的单位要越打越值钱，损失老兵才会心疼，这样玩家会在“多派人求稳”和“少派人保老兵”之间权衡。

### 要做的事
1. **经验**
   - 名册记录新增 `xp: 0`（旧记录读取时补 0）。
   - 战斗中，我方单位击毁一个敌方单位时，该单位的 `u.xp` 加 1。击杀者就是 `killUnit(o, src)` 的 `src`，且 `src.team === 'ua'`。
     - 撞击自毁的无人艇不计经验；
     - 炮击（`msta`）、TB2 打击没有 `src`，也不计经验。
   - 接受结果时，把存活单位的 `u.xp` 写回名册；阵亡单位的经验保留在记录上，理由是乘员撤出了，维修后还在。
2. **晋升**（`data.js` 新增常量 `RANKS`）
   - 0 级：新兵；
   - 3 级：老兵，生命 +1；
   - 7 级：精锐，生命 +1、移动 +1（累计）。
   - `mkUnit` 生成单位时按 `xp` 叠加加成。T-64 反应装甲升级也加生命，两者叠加。
3. **显示**
   - 选队卡片、HUD roster、单位卡片上，用 1 或 2 个小五角星表示等级，颜色 `#d8c040`；单位卡片上同时显示“老兵”或“精锐”字样。
   - 结算画面列出本关晋升的单位：“教授（反坦克组）晋升为老兵。”。
     - 角色代号取 `CHARS[pilot].call`；
     - 同类单位有多个时，后面加名册编号，例如“邮差 #5”。
4. 战斗中不在地图上画星，保持画面干净。

### 验收标准
1. `node tools/check.js` 通过。
2. `node tools/playtest.js /tmp/pt-T-15` 输出 `ERRORS none`，退出码 0。
3. 执行记录里写一段验证：把某条名册记录的 `xp` 设为 3，开战后该单位的 `max` 比基础值多 1。
4. 截图 `docs/tasks/shots/T-15/roster.png`：HUD roster 里至少有一个单位带星。

### 不要做
- 不要改敌军和商店价格。
