# T-05 战斗快捷键

- 改动范围：`game/js/ui.js`
- 依赖：无

## 任务（审查方写）

### 背景
战术游戏的老玩家习惯用键盘操作。现在战斗中只有 `1`、`2` 选武器和 `Esc` 取消。

### 要做的事
在 `ui.js` 的 `keydown` 处理里（`document.addEventListener('keydown', ...)`），在 `SCENE === 'battle'` 分支中新增：

| 按键 | 作用 | 条件 |
|---|---|---|
| `Tab` | 按 `T-64BV → 反坦克组 → D-30` 的顺序切换到下一个**存活且未行动**的我方单位，调用 `selectUnit(u)` 后 `renderHud()`；按住 `Shift` 时反向。没有可选单位时什么都不做。必须 `ev.preventDefault()`，防止焦点跳到按钮上 | `B.phase === 'player'` 或 `'deploy'`，且 `!busy` |
| `Z` | 撤销当前选中单位的移动。逻辑和点击“撤销移动”按钮完全一样，请把按钮里的代码抽成一个函数 `undoMove()`，按钮和快捷键都调用它 | 同上，且单位有 `prev`、未行动 |
| `E` | 结束回合，等同于点击“结束回合”按钮：`AUDIO.click(); enemyPhase();` | `B.phase === 'player'` 且 `!busy` |
| `T` | 切换 TB2 打击模式，等同于点击 TB2 按钮 | 同上，且 `B.tb2Left > 0` |

另外：
- 按键判断用 `ev.key.toLowerCase()`，大小写都能用。
- 输入法组合输入时（`ev.isComposing` 为真）不响应任何快捷键。
- 在 HUD 右下角按钮上补上按键提示：把“结束回合”按钮文字改为 `结束回合<small>E</small>`，TB2 按钮的小字改为 `剩余 N · T`。样式沿用现有 `.btn small`，不要改 CSS。

### 验收标准
1. `node tools/check.js` 通过。
2. `node tools/playtest.js /tmp/pt-T-05` 输出 `ERRORS none`。
3. 手动验证（在执行记录里逐条写结果）：打开 `game/index.html` 进入第一关，依次按 `Tab`（选中单位轮换）、移动一个单位后按 `Z`（回到原位）、按 `T`（TB2 按钮高亮）、再按 `T`（取消）、按 `E`（进入敌方回合）。
4. 把第一关战斗画面的截图（能看到右下角按键提示）保存为 `docs/tasks/shots/T-05/hud.png`。可以从 playtest 的 `10-selected.png` 复制。

### 不要做
- 不要改 `index.html` 和其他 JS 文件。
- 不要改变任何按钮和鼠标操作原有的行为。
