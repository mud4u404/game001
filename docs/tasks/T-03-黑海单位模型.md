# T-03 黑海战区单位模型

- 改动范围：`game/js/models.js`
- 依赖：T-02（需要用模型陈列室截图验收）

## 任务（审查方写）

### 背景
战区二“黑海”需要三个新单位。这张卡**只做模型**，数值和规则会在后续任务卡里做。
写法参照 `models.js` 里已有的 `mBtr`、`mD30` 和 `mGrad`：用 `Vox` 的 `box`、`set`、`paint`、`ell` 搭建。车头朝 `+x`，`z` 向上，模型中心在原点附近。

### 要做的事
在 `models.js` 里新增三个函数，并注册到 `UNIT_MODEL` 和 `MUZZLE`：

1. **`mMagura()`：乌克兰“海马 V5”无人艇**（键名 `magura`）
   - 真实外形：约 5.5 米长的低矮楔形快艇，没有驾驶舱，艇身很低。
   - 尺寸：`x` 从 -8 到 8，`y` 从 -2 到 2，`z` 从 0 到 2。
   - 艇艏收尖：`x` 在 6–7 时 `y` 只到 ±1，`x = 8` 时只有 `y = 0`。
   - 颜色：艇身上部 `#2a2f33`，`z = 0` 那层用 `#3a4046`。
   - 细节：`x = -4` 处一根细桅杆（`z` 从 3 到 6，颜色 `#1c1e20`），顶端放一个 `#6f93b3` 的传感器体素；艇尾 `x = -9, y = 0, z = 0..1` 是喷水推进口 `#15160f`；甲板中部 `x = -2`、`y` 从 -2 到 2、`z = 2` 刷一条识别黄 `C.yel`。
   - 不注册 `MUZZLE`，它的攻击方式是撞击。
2. **`mNeptune()`：乌克兰“海王星”岸防导弹发射车**（键名 `neptune`）
   - 真实外形：KrAZ 四轴卡车底盘，车后部是 4 个方形发射筒（2×2），行军时平放，发射时竖起。
   - 底盘和车轮：参照 `mGrad` 的写法，`wheels(v, [-8, -5, -2, 6], 4)`，底盘 `x` 从 -10 到 10，`y` 从 -3 到 3，`z` 1–2，颜色 `C.uaD`。
   - 驾驶室：`x` 7–11，`z` 3–8，颜色 `C.uaG`，前窗和侧窗用 `C.glass`，车顶刷一条 `C.yel`。
   - 发射筒：`x` 从 -10 到 4，由 2×2 个方筒组成，每个方筒截面 4×4 体素，整体 `y` 从 -4 到 3、`z` 从 4 到 11；做成像 `mGrad` 那样向车尾抬高（每向后 4 格抬 1 格）。颜色 `C.uaL`，筒与筒之间的缝用 `C.uaD`。
   - 发射筒尾端（`x = -10` 那一面）每个筒画一个 2×2 的深色口 `#1a1c18`。
   - `MUZZLE.neptune = [-10, 0, 12]`。
3. **`mRaptor()`：俄罗斯 03160 型“猛禽”巡逻艇**（键名 `raptor`）
   - 真实外形：约 17 米长的铝制高速巡逻艇，前甲板有一座遥控机枪塔，中部是驾驶舱。
   - 艇身：`x` 从 -11 到 11，`y` 从 -3 到 3，`z` 0–2。`z = 0` 层用 `#4a5057`，上面两层用 `#7b838a`。艇艏 `x` 在 9–11 时逐格收窄到 `y = 0`。
   - 驾驶舱：`x` 从 -3 到 4，`y` 从 -2 到 2，`z` 3–6，颜色 `#8a9299`；四面在 `z = 5` 开一圈窗 `C.glass`。
   - 桅杆：`x = 0, y = 0`，`z` 从 7 到 11，颜色 `#2a2d30`，`z = 10` 处横杆 `y` 从 -2 到 2。
   - 前甲板机枪塔：`x` 6–7，`y` -1–1，`z` 3–4，颜色 `#5b6166`；枪管 `x` 从 8 到 12，`y = 0`，`z = 4`，颜色 `#2b2e2a`。
   - 艇身两侧 `z = 2`、`x` 从 -8 到 -5 刷白色识别条 `C.white`。
   - `MUZZLE.raptor = [12, 0, 4]`。
