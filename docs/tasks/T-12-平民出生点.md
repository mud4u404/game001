# T-12 平民出生点被占时的处理

- 改动范围：`game/js/battle.js`
- 依赖：—

## 任务（审查方写）

### 背景
任务 1-2 的平民从路径起点 `(6,6)` 出现。`spawnCivilians()` 里一旦起点上有任何单位就直接 `break`，这一批平民推迟到下回合。
俄军空降兵开局就在 `(6,5)`，走到 `(6,6)` 站着不动时，后面几批平民都出不来。第 3 批本来就是卡着最后一回合到达的，玩家会觉得目标莫名其妙地失败了。

### 要做的事
- 修改 `battle.js` 的 `spawnCivilians()`：
  - 起点被占时，依次尝试 `cv.path[1]`、`cv.path[2]`，在第一个没有单位的格子出现；
  - 出现后把 `c.pathIdx` 设为对应的下标（0、1 或 2）；
  - 三个格子都被占才推迟到下回合（保持现在的 `break`）。
- 在 toast 里提示一次“平民绕开敌军，从旁边的路口出发”，只在没从起点出现时提示。
- 其余逻辑不变：一回合可以出现多批，按 `cv.groups` 的顺序。

### 验收标准
1. `node tools/check.js` 通过。
2. `node tools/playtest.js /tmp/pt-T-12` 输出 `ERRORS none`，退出码 0。
3. 执行记录里写一段验证：在 1-2 开局用 `window.__sf` 把一个俄军单位放到 `(6,6)`，第 1 回合的平民出现在 `(5,6)`，且 `pathIdx === 1`。

### 不要做
- 不要改任务数据和平民移动逻辑（`moveCivilians`）。
