## 任务（审查方写）

### 背景
玩家一方永远只有固定的 3 个单位，这是玩家反馈里最违和的地方。T-14 会做出击前选队，这张卡先把兵力池扩大。
两种新单位都是 2022 年 3 月基辅方向确实在用的装备：国土防卫部队的步兵班，以及第 72 机械化旅的 BMP-2。

### 要做的事
1. **数据**（`data.js`）
   - `WEAPONS` 新增三种武器：
     - `pkm`：`{ name: 'PKM 通用机枪', kind: 'line', range: 3, dmg: { inf: 2, soft: 1, la: 0, ha: 0, bld: 0 }, fx: 'mg', desc: '射程 3。压制步兵，对装甲无效。' }`

     - `roman: { name: '罗曼·特卡琴科', call: '邮差', role: '国土防卫步兵班长', face: { skin: '#dcb08a', hair: '#5a4632', style: 'helmet', beard: '#5a4632', uniform: '#5f6f3c' } }`

2. **弹药**（`battle.js` 的 `mkUnit`）：仿照 `atgm` 那一行，加一句 `if (type === 'bmp2') { u.ammo.kon = 1; }`。
   - 先确认 `ammo` 字段在开火、HUD 显示和弹药耗尽判断里是按 `w.ammo` 通用处理的。
   - 如果某处写死了 `jav`/`sting`/`nep`，把 `kon` 按同样的方式补上，并在执行记录里注明。
3. **模型**（`models.js`）
   - `mTdf()`：一个格子里画 **3 名士兵**，呈三角队形，用来表现“一个单位就是一个班”。
     - 参考 `mAtgm` / `mVdv` 的人形画法；
     - 服装橄榄绿 `#5f6f3c`，头盔 `#4d5733`，左臂一小块黄色臂章 `#d8c040`；
     - 其中一人肩扛 RPG（深色细管，前端略粗），一人端着机枪。
   - `mBmp2()`：履带式步兵战车。
     - 参考 `mT64` 的车体和履带，车体更低、更长，车首是楔形；
     - 小炮塔，一根细长的 30 毫米炮管；
     - 炮塔顶部侧面有一个导弹发射筒；
     - 涂装与 T-64 同色系。
   - 加进 `UNIT_MODEL`（`tdf: mTdf, bmp2: mBmp2`）和 `MUZZLE`（按模型实际的炮口或枪口位置填写）。
4. 这张卡**不要**把新单位放进任何任务，T-14 再做。
