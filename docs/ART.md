# 美术规范：3D 精修模型

写给做模型的执行方。好看不靠灵感，靠按顺序做对下面这些事。每一条都来自审查中实际退回过的问题。

## 1. 工作顺序（必须按顺序）

1. **先写一句话外形描述**，写进执行记录的第一行。只写轮廓和比例，不写零件。
   例：“米-8：粗圆柱座舱，圆润的玻璃机头，细长尾梁，机顶两台发动机，五叶大旋翼，旋翼直径约等于机身长。”
   写不出来，说明还没想清楚实物长什么样，先别动手。
2. **轮廓阶段**：只用不超过 10 个大形体（`profile`、`lathe`、`rbox`、`cyl`）搭出整体，不加任何小零件。
   跑一次 `model-shot`，只看两样东西：
   - **剪影**（检视图下排中间的黑色轮廓）：拿它和第 1 步写的外形描述逐句对照；
   - **黄色箭头**：它指向车头，必须和实物的车头方向一致。
   剪影不像实物，就回到这一步重做，不要往下加零件。
3. **细节阶段**：按卡片的零件清单逐项加，每个零件都要贴在所属的大形体上。
4. **自查**：逐条过第 4 节的检查表，再提交。

## 2. 形体与比例

- **轮廓决定一切**。在游戏距离下，一辆车只有几十个像素，玩家认的是轮廓，不是铆钉。轮廓错了，细节越多越难看。
- **比例从实物来**：一格 = 20，约 2 个单位 = 1 米，高度可以夸张到 1.3 倍。动手前先算好长、宽、高，写进执行记录。
- **大形体用斜面和倒角，不用直角盒子**：坦克首上装甲是斜的，教堂有坡屋顶，直升机机身是流线型。整个模型都是直角盒子时，一定哪里不对。
- **主次分明**：一个大主体，加两三个中等形体（炮塔、驾驶室、鼓座），再加小零件。不要让小零件和主体一样大（例：冰雹火箭炮的发射管组比整辆卡车还显眼，是错的）。
- **一格里的人物组**：散开占格子的一半左右，朝向错落，不要挤成一团，也不要排成方阵。

## 3. 颜色与材质

- 每个模型用 **一个主色 + 一个暗部色 + 一个亮部色**，再加少量功能色（玻璃、橡胶、金属、识别色）。不要五颜六色。
- 乌军：主色 `#5b6636`，暗部 `#474f2a`，亮部 `#66733d`。俄军：主色 `#5a5f4b`，暗部 `#3f4234`，亮部 `#686d58`。
- 画面有色调映射，**接近白色的颜色会发白过曝**。浅色墙面最亮用到 `#d8d2c4`，雪用 `#eef2f4`，不要用纯白。
- 玻璃统一 `#223044`（粗糙度 0.1）；亮着的窗户带暖色自发光；金属件金属度 0.4~0.6；其余都是哑光（粗糙度 0.6~0.95）。

## 4. 提交前检查表

- [ ] 执行记录第一行写了外形描述，剪影和它一致。
- [ ] 黄色箭头指向车头、机头或船首（检视图第一格里，车头在画面右下方）。
- [ ] `model-shot` 没有“悬空零件”警告；如果有，逐个说明为什么可以接受（例如旋翼桨尖），或者改掉。
- [ ] 和 T-64 并排的那一格里，尺寸关系合理（BMP-2 比坦克矮，卡车比坦克高，步兵到坦克车体一半高）。
- [ ] 游戏大小那一格里，一眼能认出是什么。
- [ ] 建筑的受损状态和完好状态差别明显：塌、破、熏黑、碎块，至少占三样。
- [ ] 只提交本卡点名的截图；分支从集成分支开出。

## 5. 常见错误图鉴（审查中实际出现过）

| 错误 | 出现在 | 正确做法 |
|---|---|---|
| 机头朝向 -x | 卡-52、米-8 第 1 轮 | 机头朝 +x。看黄色箭头 |
| 机身做成胖卵形 | 卡-52 第 1 轮 | 用 `lathe()` 做细长旋转体，截面高略大于宽，见 `m3Ka52` |
| 桨叶像木板 | 卡-52、米-8 第 1 轮 | 用 `rotor()`，桨叶细长（弦宽 0.6、厚 0.12） |
| 装甲筋条悬在斜面上方 | BMP-2 第 1 轮 | 建一个组，旋转到斜面角度，零件放进组里、贴着表面（见 `m3T64` 的首上反应装甲） |
| 挡泥板又厚又黑、高出车体 | BMP-2 第 1 轮 | 薄板，用车体主色，紧贴履带上方 |
| 发射管组被高架举在半空 | 冰雹第 1 轮 | 发射装置压在车台上，顶面只略高于驾驶室 |
| 建筑做成立方块、没有屋顶 | 教堂第 1 轮 | 墙矮、屋顶明显，先做好屋顶和鼓座这类轮廓特征 |
| 受损状态只是切掉一截 | 赫鲁晓夫楼第 1 轮 | 塌口参差、楼板歪挂、钢筋外露、熏黑、碎块 |
| 端面裸露（圆柱平切的大圆盘） | 米-8 第 1 轮 | 端部用半球或 `lathe` 收圆 |

## 6. 范本

| 类型 | 范本 | 看什么 |
|---|---|---|
| 履带车辆 | `m3T64` | 行走装置分层、斜面上的反应装甲组、零件密度 |
| 轮式车辆 | `m3Btr` | 船形车体、轮子三层 |
| 飞机 | `m3Ka52`、`m3Mi8` | `lathe` 机身、`rotor` 旋翼、玻璃座舱 |
| 人物 | `soldier3` | 站姿、跪姿、武器 |
| 建筑 | `m3House` | 墙、屋顶、窗框、受损状态 |
| 树 | `pine3`、`birch3` | |
